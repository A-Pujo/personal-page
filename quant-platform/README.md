# Quantitative Paper Replication Platform

A lightweight, multi-directory Python web app for replicating quantitative finance research papers. Designed specifically for shared web hosting (cPanel / Phusion Passenger) with strict CPU, RAM and network constraints.

## Architecture

```
quant-platform/
├── passenger_wsgi.py       # Phusion Passenger entry point
├── app.py                  # Flask app factory — registers all Blueprints
├── requirements.txt
│
├── mpt_portfolio/          # Sub-app: Markowitz (1952) MPT
│   ├── routes.py           # Endpoints: /mpt/assets, /mpt/optimize, /mpt/frontier
│   ├── engine.py           # Closed-form analytical optimiser (numpy)
│   └── data/
│       ├── asset_universe.json
│       └── historical_prices.csv   ← generated by scripts/
│
├── factor_analysis/        # Sub-app: Fama-French (1993) FF3
│   ├── routes.py           # Endpoints: /factor/factors, /factor/analyze
│   ├── engine.py           # OLS via normal equations (numpy + scipy)
│   └── data/
│       ├── factor_universe.json
│       └── factor_data.csv         ← generated by scripts/
│
├── scripts/
│   └── generate_sample_data.py     # Creates synthetic datasets for both sub-apps
│
└── static/                 # Vanilla JS + Chart.js frontend
    ├── index.html
    ├── css/style.css
    └── js/app.js
```

### Design principles

| Constraint               | Mitigation                                                                        |
| ------------------------ | --------------------------------------------------------------------------------- |
| RAM caps (512 MB – 2 GB) | Data loaded **inside route scope** with `usecols`; freed by GC after each request |
| CPU timeout (30–60 s)    | Closed-form matrix solutions — no iterative Monte Carlo loops                     |
| External API latency     | Static local CSV/Feather files; zero outbound HTTP at runtime                     |
| No persistent daemons    | Stateless request-response only; no Streamlit/Dash/WebSockets                     |

```bash

python scripts/generate_sample_data.py

# 3. Run the development server
python app.py

```

## Deployment (cPanel / Phusion Passenger)

1. **cPanel → Setup Python App → Create Application**
   - Python version: 3.9+
   - Application root: `quant-platform/`
   - Application startup file: `passenger_wsgi.py`
   - Application entry point: `application`

2. **SSH — activate virtualenv and install**

   ```bash
   # Copy the activation command from the cPanel Python App page
   source /home/user/.virtualenvs/quant-platform/bin/activate
   pip install --upgrade pip
   pip install -r requirements.txt
   python scripts/generate_sample_data.py
   ```

3. **Upload files** to the application root via cPanel File Manager or SFTP.

4. **Restart Passenger**
   ```bash
   mkdir -p tmp && touch tmp/restart.txt
   ```

## API Reference

### MPT Portfolio

| Method | Endpoint        | Description                                 |
| ------ | --------------- | ------------------------------------------- |
| `GET`  | `/mpt/assets`   | List available assets                       |
| `POST` | `/mpt/optimize` | Minimum-variance or target-return portfolio |
| `POST` | `/mpt/frontier` | Efficient frontier points                   |

**POST /mpt/optimize**

```json
{ "tickers": ["SPY", "TLT", "GLD"], "target_return": 0.08 }
```

`target_return` is optional (annual decimal). Omit for the Global MVP.

### Factor Analysis

| Method | Endpoint          | Description                |
| ------ | ----------------- | -------------------------- |
| `GET`  | `/factor/factors` | List assets and factors    |
| `POST` | `/factor/analyze` | OLS Fama-French regression |

**POST /factor/analyze**

```json
{ "asset": "SPY", "factors": ["Mkt-RF", "SMB", "HML"] }
```

## Mathematical Background

### MPT — Global Minimum-Variance Portfolio

$$w = \frac{\Sigma^{-1}\mathbf{1}}{\mathbf{1}^\top \Sigma^{-1} \mathbf{1}}$$

### MPT — Constrained Efficient Frontier (Lagrangian two-fund separation)

For a target return $\mu^*$:

$$w^*(\mu^*) = g + h\,\mu^*$$

$$g = \frac{C\,\Sigma^{-1}\mathbf{1} - B\,\Sigma^{-1}\boldsymbol{\mu}}{D}, \quad h = \frac{A\,\Sigma^{-1}\boldsymbol{\mu} - B\,\Sigma^{-1}\mathbf{1}}{D}$$

where $A = \mathbf{1}^\top\Sigma^{-1}\mathbf{1}$, $B = \mathbf{1}^\top\Sigma^{-1}\boldsymbol{\mu}$, $C = \boldsymbol{\mu}^\top\Sigma^{-1}\boldsymbol{\mu}$, $D = AC - B^2$.

### Fama-French Three-Factor Model (OLS)

$$R_i - R_f = \alpha + \beta_{\text{MKT}}(R_m - R_f) + \beta_{\text{SMB}}\cdot\text{SMB} + \beta_{\text{HML}}\cdot\text{HML} + \varepsilon$$

Solved via the normal equations: $\hat{\beta} = (X^\top X)^{-1} X^\top y$

## Using Real Data

Replace the generated CSV files with real data before deploying to production.

**historical_prices.csv** — one `Date` column + one column per ticker (adjusted closing prices).

**factor_data.csv** — one `Date` column + one column per analysable asset (daily returns) + `RF`, `Mkt-RF`, `SMB`, `HML` columns.

Fama-French factor data: <https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html>

For large datasets (> 20 MB), convert to Parquet for faster reads:

```python
df.to_parquet('historical_prices.parquet')
# then in routes.py: pd.read_parquet(path, columns=['Date'] + tickers)
```

## Extending with a New Paper

1. Create a new directory: `my_paper/`
2. Add `__init__.py`, `routes.py` (Blueprint), `engine.py`, `data/`
3. Register the blueprint in `app.py`:
   ```python
   from my_paper.routes import my_bp
   app.register_blueprint(my_bp, url_prefix='/my-paper')
   ```
4. Add a tab in `static/index.html` and corresponding JS in `static/js/app.js`.
